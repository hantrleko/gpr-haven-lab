# ADR-002 首页改为 v3 避险简报，经典实验室移到 /classic/

生效日期：2026-11-25。状态：接受。

## 决定

- 首页（`/`）改为 v3 报告页：规则化避险简报（地缘压力色带、避险资产评级、历史矩阵、证据等级），中英文切换。方法见 `docs/methods/v3.md`。
- 经典交互实验室整体移到 `/classic/`。事件页、API、数据文件、状态笔记、论文配套页路径不变；经典页内资源改用 `../` 前缀，「返回实验室」类链接指向 `/classic/`。
- 简报的判断文字全部由规则引擎产出：`src/havenlab/rules/rules_v3.json` 驱动，Python（`src/havenlab/report_v3.py`）与浏览器 JS（`src/havenlab/v3/report.js`）双实现，`tests/test_report_parity.py` 逐字段对齐。页面不自己写结论。
- 事件登记册仍冻结在 15 个；样本外验证仍未通过（`docs/validation.md`），简报是历史描述，不是预测，也不构成投资建议。

## 允许替换的条件

1. v3 简报与经典实验室可以再次对调首页位置，但两个 URL 都要保留可达，并写进新的 ADR。
2. 规则引擎的阈值或文案要改，改 `rules_v3.json` 并让两个引擎的 parity 测试继续通过；不允许页面端单独改写结论。
3. 若样本外验证日后通过，预测口径的改动另立 ADR，并在简报页明确区分描述与预测。

## 这次为什么这样定

受众从核对研究结果的读者扩到普通投资者和记者，首页需要一页读完的报告形态；经典实验室的计算和核对价值不变，移到 `/classic/` 后全部既有 URL 继续有效，事件页与 API 不动，外部链接不失效。
