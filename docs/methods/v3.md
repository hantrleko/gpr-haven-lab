# 方法 v3：通用事件报告

生效日期：随 V3.0.0 发布。v2 的定义保留在 `v2.md`，经典版页面继续按 v2 计算。

改任何一条定义，都新开 `v4.md`，不在本文件里改字。门槛和文字模板的机器版本在 `src/havenlab/rules/rules_v3.json`，两边不一致时以本文件为准，并按勘误处理。

## 适用范围

任意日期 D 都能生成一份报告：15 个内置事件、用户自己输入的日期，以及首页的「最近 30 天」。三者用同一套规则。报告只描述 D 之后各资产的走势在它自己历史里有多少见，不预测之后的走势。

## 数据

日度收盘价，来自 `docs/v3/series.json`。日元和瑞郎按 1/汇率 计，上涨表示该货币走强。美国国债用 IEF 复权价，含利息再投资。比特币周末也有收盘价。每个资产只用它自己有数据的日子。

## 窗口

期限 h 取 7、30、91 个日历日，叫作一周、一个月、三个月。主期限是 30 天。

对资产 X，起点 s 是 X 在 D 之前的最后一个收盘日。终点 e 是不晚于 s + h 的最后一个收盘日。窗口收益 r = 100 × ln(P(e) / P(s))。若 s + h 晚于 X 的最后一个收盘日，窗口记为未结束，只报告已有的收益，不评级。

## 常态分布与百分位

历史窗口：X 的每一个收盘日 t 都当作起点，用同样的方法算 h 天收益。去掉终点超出数据的窗口，再去掉起点与 s 相距不超过 h 天的窗口。剩下的窗口个数记为 N。

百分位 p = (低于 r 的个数 + 0.5 × 等于 r 的个数) / N。

N < 250 时，X 记为「历史太短」，不评级。

## 资产分组

- 避险候选：黄金、白银、日元、瑞郎、美国中期国债、比特币、美元指数。
- 风险基准：标普 500（默认）、沪深 300、恒生。一次报告只用一个基准，用户可以切换。
- 冲击传导：布伦特原油。只报告涨跌和百分位，不评级。

## 评级

k 是这一期限下有评级资格的避险候选个数。同时看 k 个资产，偶然有一个落进尾部的机会会变大，所以「明显」的门槛按 k 收紧：

- 明显走强：r > 0 且 p ≥ 1 − 0.20 / k。
- 偏强：r > 0 且 p ≥ 0.80，但没达到明显走强。
- 明显走弱：r < 0 且 p ≤ 0.20 / k。
- 偏弱：r < 0 且 p ≤ 0.20，但没达到明显走弱。
- 其余为常态。

k = 7 时，明显走强要求 p ≥ 0.9714。

## 风险基准是否下跌

基准 B 的主期限收益 r_B 与百分位 p_B：

- 明显下跌：r_B < 0 且 p_B ≤ 0.20。
- 小幅下跌：r_B < 0，未达到明显下跌。
- 没有下跌：r_B ≥ 0。

基准没有下跌时，这次不算避险考验。资产走强照常报告，但结论句不写「起到避险作用」。

## 地缘压力

用 Caldara–Iacoviello 日度 GPR。m 是 (s_G, s_G + 30 天] 内 GPR 的均值，s_G 是 GPR 在 D 之前的最后一天。参照分布是 s_G 之前 3650 天里每一天的「截至当天的 30 天均值」，只用过去的数据。百分位 p_G 按上面的公式算。窗口内不足 5 个 GPR 日时，地缘压力记为数据不足。

- p_G ≥ 0.90：很高。
- 0.75 ≤ p_G < 0.90：偏高。
- 其余：一般。

## 结论与证据等级

只看主期限。设「明显走强」的资产集合为 S，「偏强」的为 L。

| 情形 | 结论 | 证据等级 |
|---|---|---|
| 基准明显下跌，S 非空 | 风险资产明显下跌，S 明显走强 | 强 |
| 基准小幅下跌，S 非空 | 风险资产小幅下跌，S 明显走强 | 中 |
| 基准下跌，S 为空，L 至少两个 | 风险资产下跌，L 走强，但幅度不足以排除偶然 | 中 |
| 基准下跌，S 为空，L 一个 | 同上 | 弱 |
| 基准下跌，S、L 都为空 | 风险资产下跌，没有资产明显走强 | 无 |
| 基准没有下跌 | 不构成避险考验 | 无 |
| 主期限窗口未结束 | 窗口还没结束，先不下结论 | 无 |

基准下跌（明显或小幅）时，若有避险候选在主期限「明显走弱」，结论句后面再接一句：这些资产也明显下跌，没有起到避险作用。证据等级不因这句话改变。

证据等级只说明这一次的价格走势有多少见，不说明原因。

## 面向读者的写法

报告正文不写「第几百分位」。资产走势按百分位 p 写成：p < 0.5 时「弱于历史上 (1 − p) 的一个月走势」，p ≥ 0.5 时「强于历史上 p 的一个月走势」，比例取整到百分之一。地缘压力写成「高于过去十年里 p 的时候」。「明显走强」的门槛写成「历史上最强的 0.20 / k」，保留一位小数。最近 30 天的报告把「事件后 30 天」写成「最近 30 天」。

## 历史对照

对每个避险候选，在 15 个内置事件上按同一规则评级，报告各评级的次数和主期限收益中位数。报告的日期若正好是某个内置事件，计数时去掉它自己。这一栏只描述历史。

## 提示

报告按条件附上这些提示：

- 总是附上：本站的样本外检验没有通过，历史对照不构成预测。
- 总是附上：日期是看过行情之后挑的，结果会偏乐观。
- k > 1：同时看了 k 个资产，门槛已按 k 收紧。
- 主期限未结束。
- 有资产因历史太短或缺数据没有评级。
- 白银或布伦特被评级或报告时：连续期货在换月日可能有跳变。
- GPR 数据止于窗口结束之前。
- 基准没有下跌。

## 实现

Python（`src/havenlab/report_v3.py`）在构建时生成内置事件和最近 30 天的报告。浏览器（`src/havenlab/v3/report.js`）用同一份规则生成用户自定义日期的报告。CI 用同一份数据分别跑两边，要求评级、等级和文字完全一致，数值误差不超过 1e-9。

## 不做的事

不把评级写成买卖建议。不因为某次结果好看就改门槛。不把用户输入的日期写进事件登记册。
