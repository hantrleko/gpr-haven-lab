# 什么情况下这套结论失效

下面五条里任何一条发生，页面上的状态描述和「避险分流」句子都要停用，直到重新跑完验证并写进勘误。

1. **黄金口径再变。** 公布序列现在是新浪伦敦金。若改成另一条现货或重新用期货，A 阶段对照过的累计收益不再可沿用。
2. **GPR 被作者修订。** Caldara–Iacoviello 的日度文件若整体重发，高压月份和相似月都会变。
3. **样本外门槛失败。** `docs/validation.md` 里的 pinball、PIT、覆盖率或三个基线有一项不通过。这时只能说同期路径，不能说未来 3 个月的条件分布。
4. **事件登记册被事后加塞。** 15 个事件冻结在版本 2.3。未按「先提交规则、再等下一次冲击」加入的日期，会使事件档案失去现在的含义。状态层的计算不依赖这份名单，但事件页上的句子会失效。
5. **数据源断供且被静默换成别的数。** FRED 的 LBMA 黄金已经 404。Stooq 现货会被脚本挑战挡住。这类失败必须写进 `data/sources_status.json`。用另一条序列顶上而不改版本，整页失效。
