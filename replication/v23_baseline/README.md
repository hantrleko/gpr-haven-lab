# V2.3 基线（黄金 = Yahoo GC=F）

这些文件是切换到现货口径之前的发布结果，对应版本 V2.3、样本 2007-08 至 2026-09、构建日 2026-10-13。

- `event_window_summary.csv`：15 个事件、6 个月与 12 个月窗口。霍尔木兹 6 个月黄金累计为 −15.79。
- `panel_monthly.csv`：月度面板，黄金收益来自 GC=F 月末收盘。
- `event_daily_car.csv`：日度均值调整 CAR。
- `provenance.json`：当时的版本与样本针。
